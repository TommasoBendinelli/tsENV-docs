\docTitle{Stage: Surrogate Training}
\phantomsection\label{docstart:surrogate_training_stage}

This stage trains and calibrates a neural classifier on the bootstrap candidate pool after cheap filtering.
The surrogate estimates whether the simulator ground-truth label is recognizable from the agent-visible time series.
It is trained on bootstrap-policy runs and then frozen before scoring the production-policy pool.
Logs are trained in WandB.

\section*{Main Driver}

\begin{DocCode}
env/bin/python workflows/surrogate/train_surrogate.py \
  --model SIMULATOR \
  --policy BOOTSTRAP_POLICY_ID \
  --surrogate-id SURROGATE_ID \
  [--noise-level none|low|high|all] \
  [--seed SEED]
\end{DocCode}

\section*{Inputs}

\begin{itemize}
\item \code{plans/<bootstrap_policy_id>/run_nodes.jsonl}, required for labels, family-grouped splits, and leakage checks
\item \code{plans/<bootstrap_policy_id>/run_edges.jsonl}, required for labels, family-grouped splits, and leakage checks
\item \code{runs/model_record.json}
\item \code{runs/<run_id>/data.parquet}
\item \code{experiment_config.json}
\item \code{description_levels.json}, for label mapping only
\item \code{noise_adder.py}, when training on noisy materializations
\end{itemize}

\section*{Critical Rules}

\begin{itemize}
\item Include both intervention classes and the \code{no_intervention} class.
\item Splits must be grouped by \code{family_id}.
\item No \code{family_id} may appear in more than one of train, validation, and test.
\item The production policy used for benchmark selection must not be used to train or calibrate the same surrogate version.
\item The surrogate input should match the agent-visible time-series representation for the target noise regime.
\end{itemize}

\section*{Outputs}

Outputs are written under:

\begin{DocCode}
models/simulink/<simulator_id>/surrogates/<surrogate_id>/
\end{DocCode}

Expected files:

\begin{itemize}
\item \code{model.pt}
\item \code{model_config.json}
\item \code{training_manifest.jsonl}
\item \code{training_metrics.json}
\item \code{calibration_report.json}
\item \code{thresholds.json}
\end{itemize}
